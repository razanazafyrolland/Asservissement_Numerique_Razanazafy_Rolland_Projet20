# Fault Detection using Luenberger Observer

##  Description
This project focuses on fault detection in dynamic systems using a Luenberger observer. The goal is to detect anomalies by comparing the real output with the estimated output.

##  Tools and Technologies
- Python 3
- NumPy
- Matplotlib
- SciPy
- python-docx

##  How to Run

1. Install required libraries:
pip install numpy matplotlib scipy python-docx
2.Run the script:
python "Projet 2.py"
